# Combined best results: every simplex-map variant (aggregated from reproduction_*.md)

Maintenance: whenever a new `reproduction_<MMDD>.md` lands, re-aggregate this file from all
reproduction_*.md reports (and the per-run dump `context/runs_0920.json`, regenerated by
`experiments/osc/dump_runs.py`), then update the source column. Do not hand-edit a cell without
re-checking it against its source report / the dump.

What a row is. One row per variant = attention map x its hyperparameters (q, window d, scale, warmup).
LR and seed are not variants: each row is the validation-selected best run over all seeds x LRs tried
for that variant, and the LR / seed of that run are reported as columns. `runs` = number of
(seed, LR) runs pooled for the row; many rows are single runs (q sweep) and should be read as ranges.

Conventions.
- Selection is validation-only (`reproduction_0907.md` §4, `reproduction_0913.md` §6). Degenerate primary
  monitor -> val BLEU@4x fallback and the last.ckpt ladder (all reverse rows; mqmtar `entmax`).
- † = exact tie on the validation selection value with no validation tie-break ladder available; the
  tied run with the best test ladder is shown and the alternatives are listed under "Ties" below.
  This is a test-based tie-break among validation-equal runs; quote † rows with that caveat.
- Cells are exact-match % on 100 test samples/length (paper: 1K) -> about ±4 pt SE at p = 0.8.
- `skip` = not evaluated because a shorter length scored exactly 0 (early-stop ladder).
- Row order within each table: softmax, entmax family, then Stieltjes dense (no scale, AS), windowed
  (no scale, AS); within a block ascending q, then ascending d, then 10k before 20k warmup.
- `scale`: `-` = none; `AS` = adapt-softplus-tanh adaptive scale (ASEntmax's); `AS, zero-init` =
  `attn_scale_zero_init=0.05`. Stieltjes `d = inf` = dense (`stieltjes_window=0`); otherwise
  `stieltjes_window=d`. Method keys are the `run_one.sh` names.
- Excluded: `stieltjes_ref` / `stieltjes_triton` (one-off eager-vs-Triton implementation comparison runs,
  not variants).

## Caveats per row

- sort `aswstieltjes_q2` 4x = 62 is a single-seed outlier (seeds 62/1/0, mean 21 ± 29; 0929 §8.1). Do not quote 62 as the row value.
- mqmtar `asentmax` (HF-init scale, 10k warmup) pools 1e-4/2e-4 (0907) and 4e-4 (0920); 1 of 7 runs escaped the plateau. With 20k warmup 0/3; zero-init at 10k 0/3; zero-init + 20k at 4e-4 0/3; only zero-init + 20k at 2e-4 works (3/3).
- mqmtar `entmax` (10k) is a last.ckpt ladder of the one run that escaped (at 258k).
- mqmtar `stieltjes` (q=4) 2e-4 s2 is missing its 1024x rung (eval timed out; 0913 §7); does not affect the selected row.
- reverse: BLEU@4x fallback is a weak selector (0913 §4.3); e.g. `stieltjes` 6.4e-3 s2 (99/85 at 1.5x/2x) is not selected.
- sort/copy single-seed q sweep rows (`*_q2`, `*_q8`, `asstieltjes_*`) carry up to ±40 pt seed noise at the informative length.
