\begin{abstract}
We propose architectural changes for sharper focus of probabilities from logits in attention and Mixture-of-Experts layers by replacing the softmax function with Stieltjes transform based functions. The idea is to check whether we can get to better OOD and length generalization as well as better reasoning capabilities because softmax is inherently dimension dependent whereas the Stieltjes transform is not as dependent if at all. Of course there may be variations where it doesnt give much gain and so we might have to analyze where we do and don't get advantages. 
\end{abstract}

\section{Introduction}
The motivating principle is that if we're given so-called logits $x\in\mathbb{R}^n$, there is the popular way to get a probability distribution out of it which is via the arg-softmax function \begin{align*}\left(\frac{e^{\beta x_i}}{\sum\limits_j e^{\beta x_j}} \right)_i\end{align*}
There is a variational way of interpreting this which is quite popular in statistical physics, probability and theoretical computer science: 
\begin{align*}
\max_{y \in \Delta_n} x^\top y + \frac{1}{\beta}H(y)
\end{align*}
where $\Delta_n = \{y\in \mathbb{R}^n \vert y_i \geq 0 , \sum\limits_i y_i = 1\}$ is the probability simplex and $H(y) = \sum\limits_i y_i \log y_i - y_i $ is the entropy function
It can be easily checked that the maximum value of this \begin{align*}\frac{1}{\beta}\log \sum\limits_i e^{\beta x_i}\end{align*} (which is in math circles actually what's referred to as softmax) and the optimal $y$ attaining this is exactly the arg-softmax defined above.

The way to view the variational maximization problem is that without the entropy function, the value would literally be the maximum value of the $x_i$s and $y$ would be the one-hot vector on the index attaining the maximum. However the max function is not smooth. So you add some strongly convex (on the space under consideration that is $\Delta_n$) function like the entropy function to make it smooth but still an estimator of the maximum. 

However, there's no requirement to use the entropy function and you could use a different strongly convex regularizer as well. 
I won't get into why the following regularizers are better but suffice to say that they more sharply capture the maximum value in a smooth fashion. And the argsoftmax suffers from an issue that as the dimension $n$ becomes larger, the probability starts becoming closer and closer to uniform distribution so is non-informative. This is essentially also the punchline of the pseudo-proofs in the ``softmax is not enough'' paper.

There are two kinds of regularizers under consideration and the corresponding ``argmax'' is
\begin{enumerate}
\item $- \sum\limits_i \log y_i$ and argmax is $\left(\frac{1}{\lambda_1 - x_i}\right)_i$
\item $\frac{-q}{q-1}\sum\limits_i y_i^{1-1/q}$ and argmax is $\left(\frac{1}{(\lambda_q - x_i)^q}\right)_i$
\end{enumerate}
where the $\lambda_q$ is such that $\lambda_q > x_i$ for all $x_i$ and which makes the sum of the entries in the argmax sums to 1. It can be seen that this is unique and one can always find the $\lambda_q$ via binary search/1D line search.
